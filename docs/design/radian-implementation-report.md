## Leistung und praktische Grenzen

Es gibt keinen eigenen Abruf pro Stern. Teilweise fehlende Quellen werden als letzter verfügbarer Stand kenntlich gemacht.

Die Schreibkoordination schützt beteiligte Workflow-Schritte innerhalb desselben Serverprozesses. Sie sperrt keine extern gestarteten Programme oder beliebige Änderungen durch andere Anwendungen. Verbrauch wird anhand tatsächlich gemeldeter Anbieterwerte erfasst; eine verspätet abgerechnete Antwort kann die Grenze noch überschreiten. Es werden keine erfundenen Token- oder Zeitersparnisse angezeigt.

Der ursprünglich gemeldete native Chat-Ausstieg ließ sich vor dem Umbau nicht eindeutig reproduzieren. Die abgesicherten Navigationsfälle und die entfernte vorübergehende Projektidentitätslücke sind belegt; eine exakte Ursachenbehauptung für den ursprünglichen Vorfall wäre nicht belegt.
